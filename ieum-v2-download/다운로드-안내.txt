확인 범위
홈·프로젝트·컬렉션·프로젝트 상세 화면을 확인하고, HTML/JavaScript/CSS/JSON/SVG에서 연결한 공개 파일을 재귀적으로 수집했습니다. 배포 파일의 경로와 내용은 원본 그대로 보존했습니다. 화면의 인라인 그래픽과 프로젝트·곡 등의 내장 데이터는 원본 JavaScript/HTML에 포함되어 있습니다.

별도 안내
- 이것은 공개된 사이트의 배포본입니다. React 개발용 원본 TSX/JSX, 저장소 이력, 서버 내부 파일은 포함되어 있지 않습니다.
- 브라우저에 사용자가 별도로 저장한 녹음·프로필 등 개인 데이터는 포함되어 있지 않습니다.
- demo-stems의 WAV 3개는 사이트가 합성 시연음으로 명시한 자료이며 실제 사람의 보컬 녹음이 아닙니다. 제공된 출처·라이선스 정보는 demo-stems/manifest.json에 보존했습니다.
- index.html은 루트 기준 경로를 사용하므로 직접 더블클릭해서 여는 것보다 이 폴더를 웹 서버의 루트로 제공해야 배포 당시처럼 연결됩니다.
